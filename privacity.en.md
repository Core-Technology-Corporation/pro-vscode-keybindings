# 🔒 Privacy Policy

*[🌐 Español](privacity.md)*

**Pro VSCode Keybindings** does not collect, store, or transmit any personal or usage data.

## What the extension does

- Registers keyboard shortcuts and commands that run **locally**, inside your own VS Code instance.
- The smart commands (detect project type, commit, push, open in GitHub Desktop, etc.) only interact with your local file system and with `git`/GitHub Desktop installed on your machine.

## What it does NOT do

- Does not send data to external servers.
- Does not use analytics or telemetry.
- Does not access the internet except for the normal `git push`/`git pull` operations you initiate yourself with your own credentials.
- Does not read or collect the contents of your files beyond what's needed to run the command you invoked (e.g., standardizing the `console.*` calls of the open file when using "♻️ Clean consoles" or "⚡ Super").

## Permissions

The extension only uses standard VS Code APIs to execute commands, read the Explorer's file tree, and open a terminal. It does not request any additional operating system permissions.

## Contact

If you have questions about this policy, open an issue on the [GitHub repository](https://github.com/alvarosiles/pro-vscode-keybindings/issues).
